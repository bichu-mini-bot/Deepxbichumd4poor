# 💝 BICHU MD - FREE WhatsApp Bot

> *"Made for those who can't afford premium bots"*

---

## 🌟 About

**BICHU MD** is a **100% FREE** WhatsApp bot with **200+ commands**. 
It provides AI chat, downloads, stickers, games, anime, and tools 
**completely FREE** for everyone!

### 🎯 Mission
**"Har WhatsApp user ko FREE mein AI, Downloads, aur Utility tools provide karna"**

---

## ✨ Features

### 🤖 AI Commands
- `.ai` - AI Assistant (Gemini/ChatGPT)
- `.chatgpt` - ChatGPT
- `.gemini` - Google Gemini
- `.llama` - Llama AI
- `.deepseek` - DeepSeek
- `.flux` - Image Generation
- `.sdxl` - Stable Diffusion XL

### 📥 Download Commands
- `.play` - Play audio
- `.ytmp3` - YouTube to MP3
- `.ytmp4` - YouTube to MP4
- `.tiktok` - TikTok video
- `.instagram` - Instagram video
- `.facebook` - Facebook video
- `.spotify` - Spotify song

### 👥 Group Commands
- `.add` - Add member
- `.kick` - Remove member
- `.kickall` - Remove all non-admins
- `.promote` - Make admin
- `.demote` - Remove admin
- `.tagall` - Tag everyone
- `.hidetag` - Hidden tag
- `.mute` - Mute group
- `.unmute` - Unmute group
- `.linkgc` - Get group link
- `.poll` - Create poll
- `.welcome` - Enable welcome

### 🛠️ Tools
- `.translate` - Translate text
- `.calc` - Calculator
- `.weather` - Weather info
- `.qr` - QR Code generator
- `.currency` - Currency converter
- `.tts` - Text to Speech
- `.tinyurl` - Short URL
- `.removebg` - Remove background

### 🎮 Fun & Games
- `.joke` - Random joke
- `.meme` - Random meme
- `.truth` - Truth question
- `.dare` - Dare challenge
- `.tictactoe` - Tic-tac-toe
- `.rps` - Rock Paper Scissors
- `.guess` - Guess number
- `.8ball` - Magic 8 Ball

### 🎨 Sticker & Anime
- `.s` - Image to sticker
- `.sticker` - Make sticker
- `.emojimix` - Mix emojis
- `.waifu` - Random waifu
- `.neko` - Random neko
- `.animesearch` - Search anime
