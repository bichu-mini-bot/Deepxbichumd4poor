# 📁 Temp Folder

## Purpose
This folder stores **temporary files** like:
- Downloaded media
- Converted audio/video
- Generated images
- Cache files

## Auto-Cleaning
- Files are auto-deleted after use
- Folder is cleaned on bot startup
- Do not store important files here

## File Types
- `*.mp3` - Audio files
- `*.mp4` - Video files
- `*.jpg/png` - Images
- `*.webp` - Stickers

## Safety
⚠️ Files here are **NOT** backed up
⚠️ Files are **temporary** only
⚠️ Use `./temp` for runtime only
